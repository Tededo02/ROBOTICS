# ROS 1 – Vehicle Odometry and Trajectory Tracking

Robotics coursework project developed using **ROS 1 (Robot Operating System)**, focused on vehicle odometry, trajectory estimation, and localization.

The project explores the development of a modular robotics system using ROS nodes, inter-process communication, and coordinate frame transformations to manage and process odometry-related information.

## Project Overview

The implementation focuses on core components of a ROS-based robotics pipeline:

- **ROS Node Architecture:** Organization of robotics functionalities into separate nodes communicating through ROS topics and message interfaces.
- **Vehicle Odometry:** Processing and management of odometry information for vehicle motion tracking.
- **Trajectory Estimation:** Handling vehicle position and motion information within a consistent reference frame.
- **Coordinate Transformations:** Use of ROS `tf` to manage transformations between coordinate frames.

## Technologies

- **Framework:** ROS 1
- **Core Concepts:** ROS Nodes, Topics, Messages, Odometry, `tf`
- **Development Environment:** ROS Catkin Workspace
